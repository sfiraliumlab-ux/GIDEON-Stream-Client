## 🌀 Суть и Принцип Работы Кодека (Версия 4.0)

Данный репозиторий реализует и наглядно доказывает на практике концепцию **«Комплементарной экономии 50% трафика»**, сформулированную в R&D материалах проекта GIDEON (Черненко С. Л., Басаргин О. С.). 

В отличие от версии 3.0, где дискретное сканирование одной нитью порождало мозаичный эффект («кубики»), в версии 4.0 реализована **Истинная Фрактальная Сфираль (Fractal Sphiral Mesh)**. Алгоритм полностью сохраняет сложную асимметрию реального мира (все объекты слева и справа остаются на своих местах), но преодолевает барьер пиксельности за счет рекурсивного сгущения растра:

1. **Кодирование (Трансляция):** Скрипт попиксельно сканирует прямоугольную матрицу сенсора, пересчитывая пространственные координаты каждой точки в её индивидуальную фазу на Сфирали. В файл записывается строго левый полувиток ($V_{-}$, параметр $t \in [-1.0, 0.0]$). Данные, передаваемые по сети или через файл, сжимаются ровно в 2 раза.
2. **Фрактальное декодирование (Регенерация):** Принимающая сторона считывает половинный волновой след, на лету восстанавливает встречный правый виток ($V_{+}$) по закону зеркальной антисимметрии ($P_{left} = -P_{right}$), а затем запускает рекурсию второго порядка (Микро-витки). Каждая макро-координата порождает матрицу суб-пикселей, сдвинутых по экспоненте золотого сечения:
$$\Delta = \pm \frac{1}{\Phi} \quad (\approx 0.618)$$
Это позволяет на стороне клиента на лету формировать плотную, сглаженную пространственную сетку данных (меш), заполняя пустоты растра без увеличения сетевого трафика.

## 🖥 Архитектура Мониторинга (4 Рабочих Окна)

Для объективной и прозрачной оценки результатов пользователю предоставлена четырехоконная аналитическая среда:
* **Окно 1 (Большое левое сверху):** Исходный несжатый HD-видеопоток с веб-камеры (Сенсор).
* **Окно 4 (Большое правое сверху):** ОБЪЕКТИВНЫЙ РЕЗУЛЬТАТ — восстановленный из 50% файла полный асимметричный кадр через фрактальную сетку сгущения.
* **Окно 2 (Маленькое левое снизу):** Диагностическая 3D-матрица сжатого макро-витка $V_{-}$.
* **Окно 3 (Маленькое правое снизу):** Диагностическая 3D-матрица регенерированного макро-витка $V_{+}$.

## 🚀 Инструкция для Тестирования

1. Запустите приложение в браузере: **[sfiraliumlab-ux.github.io/GIDEON-Stream-Client/](https://github.io)**
2. Обязательно сбросьте кэш браузера комбинацией клавиш **Ctrl + F5** (или *Cmd + Shift + R* на Mac) для загрузки фрактального ядра v4.0.
3. Активируйте сенсор кнопкой **«Включить камеру»** (Окно 1 покажет видео, Окно 2 начнет оцифровку).
4. Разместите в кадре асимметричный предмет (например, телефон с одной стороны), чтобы проверить честность развертки.
5. Нажмите **«Запаковать в Сфираль 50%»** для сохранения сжатой фрактальной матрицы в файл `.json`.
6. Обновите страницу через обычную клавишу **F5** (имитация чистого удаленного компьютера — правые окна станут пустыми).
7. В блоке приема нажмите **«Импортировать Сфираль»** и выберите сохраненный файл.
8. В Окне 4 мгновенно развернется плотная, сглаженная прямоугольная картинка вашей комнаты, доказывающая точность волновой регенерации.

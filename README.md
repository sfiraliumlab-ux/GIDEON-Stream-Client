# GIDEON // Stream Client P2P Pro v2.5

> **Прототип P2P-кодека голографической связи с аппаратным сжатием трафика на 50% на базе зеркальной антисимметрии Сфирали Времени.**

## 🌀 Суть инженерного решения

Данное приложение наглядно демонстрирует на практике феномен **«комплементарной экономии 50% трафика»**, описанный в исследовательских материалах проекта GIDEON (Черненко С. Л., Басаргин О. С.). 

В классических 3D-системах для передачи объемных объектов требуется транслировать координаты и цвета всех точек облака вокселей. Архитектура GIDEON задействует фундаментальный закон инверсии хиральности:

1. **На стороне отправки (Трансляция):** Кодек захватывает медиапоток и кодирует его строго в левый полувиток Сфирали ($V_{-}$, параметр $t \in [-1.0, 0.0]$). Правое крыло полностью отсекается. Пакет данных, передаваемый по сети, весит ровно в 2 раза меньше.
2. **На стороне приема (Регенерация):** Клиент получает половинный поток и на лету, прямо в браузере, зеркально достраивает правый виток ($V_{+}$) из пустоты на основе уравнения антисимметрии: 
$$P_{left} = -P_{right}$$

## 🛠 Функционал интерфейса Pro версии

- **Автономная самодиагностика**: Безопасный запуск без обращения к внешним серверам. Режим по умолчанию генерирует канонический сине-красный математический тест-паттерн.
- **Осознанное управление приватностью**: Веб-камера при старте полностью отключена. Включение и полное уничтожение потока из оперативной памяти происходит строго по команде пользователя.
- **Внешний P2P-сигнал (WebRTC)**: Интегрирован ленивый вызов встроенной библиотеки PeerJS для переключения в режим реального сетевого соединения между удаленными узлами.

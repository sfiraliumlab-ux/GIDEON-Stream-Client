## 🌀 Суть и Принцип Работы Кодека

Данный репозиторий реализует и наглядно доказывает на практике концепцию **«Комплементарной экономии 50% трафика»**, сформулированную в R&D материалах проекта GIDEON (Черненко С. Л., Басаргин О. С.). 

В отличие от примитивного зеркального копирования пикселей, искажающего асимметричный реальный мир, кодек работает по принципу **сквозного топологического сканирования**:

1. **Кодирование (Трансляция):** Скрипт сканирует прямоугольную матрицу сенсора, пересчитывая пространственные координаты каждого пикселя в его индивидуальную фазу на Сфирали. В файл записывается строго левый полувиток ($V_{-}$, параметр $t \in [-1.0, 0.0]$). Данные, передаваемые по сети или через файл, сжимаются ровно в 2 раза.
2. **Декодирование (Регенерация):** Принимающая сторона считывает половинный волновой след, на лету восстанавливает в пространстве встречный правый виток ($V_{+}$) по закону зеркальной антисимметрии ($P_{left} = -P_{right}$), а затем осуществляет обратный маппинг — разворачивает 3D воксели в плоскую прямоугольную картинку кадра.

## 🖥 Архитектура Мониторинга (4 Рабочих Окна)

Для объективной оценки результатов пользователю предоставлена четырехоконная аналитическая среда:
- **Окно 1 (Большое левое):** Исходный несжатый HD-видеопоток с веб-камеры (Сенсор).
- **Окно 4 (Большое правое):** ОБЪЕКТИВНЫЙ РЕЗУЛЬТАТ — восстановленный из 50% файла полный асимметричный кадр.
- **Окно 2 (Маленькое левое):** Диагностическая 3D-матрица сжатого витка $V_{-}$.
- **Окно 3 (Маленькое правое):** Диагностическая 3D-матрица регенерированного витка $V_{+}$.

## 🚀 Инструкция для Тестирования
1. Запустите приложение: **[sfiraliumlab-ux.github.io/GIDEON-Stream-Client/](https://github.io)**
2. Активируйте сенсор кнопкой **«Включить камеру»** (Окно 1 покажет видео, Окно 2 начнет оцифровку).
3. Нажмите **«Запаковать в Сфираль 50%»** для сохранения сжатой матрицы в `.json` файл.
4. Выключите камеру или обновите страницу сайта (эмуляция чистого удаленного компьютера).
5. В блоке приема нажмите **«Импортировать Сфираль»** и выберите сохраненный файл.
6. В Окне 4 мгновенно развернется плотное прямоугольное изображение, подтверждающее точность волновой регенерации.
